## MODIFIED Requirements

### Requirement: 啟動時背景靜默檢查版本
應用程式在啟動進入主介面時，系統必須在背景非同步向 GitHub Releases 查詢最新版本資訊，並且在無新版本或網路異常時保持靜默。當測試模式開啟時，應包含預發布版本(Pre-release)；當測試模式關閉時，僅包含正式版(Latest)。

#### Scenario: 檢測到有正式新版本發布（測試模式關閉）
- **WHEN** 應用程式啟動且測試模式為關閉狀態，且 GitHub Releases 上的最新正式標籤版本（例如 v1.0.1）高於目前執行版本（例如 v1.0.0）
- **THEN** 系統彈出版本更新提示對話框，顯示新版本號、更新日誌說明，以及「稍後再說」與「立即更新」按鈕

#### Scenario: 檢測到有預發布新版本發布（測試模式開啟）
- **WHEN** 應用程式啟動且測試模式為開啟狀態，且 GitHub Releases 上的最新版本（包含預發布版，例如 v1.0.1-beta）高於目前執行版本（例如 v1.0.0）
- **THEN** 系統彈出版本更新提示對話框，顯示新版本號、更新日誌說明，以及「稍後再說」與「立即更新」按鈕

#### Scenario: 遠端版本相同或更低
- **WHEN** 應用程式啟動且 GitHub Releases 上的對應目標版本等於或小於本機版本
- **THEN** 系統不彈出任何通知或對話框，使用者無感正常進入應用

#### Scenario: 網路連線失敗或超時
- **WHEN** 應用程式啟動時處於離線狀態或 GitHub API 請求超過 5 秒未回應
- **THEN** 系統靜默結束檢查，不中斷使用者操作也不顯示錯誤訊息
