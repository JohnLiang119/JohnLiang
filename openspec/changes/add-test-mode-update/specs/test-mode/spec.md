## Purpose

提供使用者與開發者在應用程式中切換測試模式的機制，以改變更新檢查與其他潛在測試相關行為的範圍。

## ADDED Requirements

### Requirement: 切換測試模式
系統必須提供選項讓使用者開啟或關閉測試模式，且需保存此狀態以供其他服務讀取。

#### Scenario: 開啟測試模式
- **WHEN** 使用者在設定面板中開啟「測試模式」開關
- **THEN** 系統將測試模式狀態保存為開啟

#### Scenario: 關閉測試模式
- **WHEN** 使用者在設定面板中關閉「測試模式」開關
- **THEN** 系統將測試模式狀態保存為關閉
