## Purpose
提供一個能自動載入雲展網電子書，並攔截網路請求以獲取原始高畫質圖片的下載功能，以解決手動下載的繁瑣。

## ADDED Requirements

### Requirement: 使用者可以提供網址並下載電子書圖片
系統必須能接收一個或多個雲展網電子書的網址，並自動將其中的頁面圖片下載至本機資料夾中。

#### Scenario: 成功下載單一電子書
- **WHEN** 使用者輸入單一雲展網電子書的 URL 執行腳本
- **THEN** 系統會自動建立對應的資料夾，並將所有頁面的圖片 (1.jpg, 2.jpg...) 儲存至該資料夾中。

#### Scenario: 成功下載多本電子書
- **WHEN** 使用者輸入多個電子書 URL，或提供包含 URL 的清單檔案
- **THEN** 系統會依序處理每個 URL，並將圖片分別儲存到對應的各個資料夾中。

### Requirement: 腳本需模擬真實瀏覽以解除圖片保護
系統必須使用無頭或有頭的瀏覽器 (如 Puppeteer / Playwright / Selenium) 來真實渲染網頁，以觸發雲展網前端 JS 解密與載入圖片的邏輯。

#### Scenario: 攔截並擷取正確的圖片 URL
- **WHEN** 腳本在背景開啟電子書網頁並模擬翻頁
- **THEN** 腳本必須成功攔截並取得真實的圖片資源 (Network Requests)，而非使用已失效的硬編碼路徑 (如直接猜測 files/large/1.jpg)。
